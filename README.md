# Medical Service Mobile App – UI/UX Design

## Overview

A complete mobile UI/UX design project for a medical service application that enables users to discover doctors, book appointments, make payments, and communicate with doctors.

## Key Features

* User onboarding & authentication
* Doctor search and profiles
* Appointment booking
* Date & time selection
* Payment method
* Appointment confirmation
* Doctor-patient chat
* User profile & appointments

## Design Process

* Wireframing
* User Flow
* Design System
* High-Fidelity UI Design
* Interactive Prototype
